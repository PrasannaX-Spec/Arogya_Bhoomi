Ferrous Sulphate Foliar Guidance Special Branch

Ferrous Sulphate follows the platform's foliar application guidance rather than the soil-dose multiplier calculation.

FOLIAR APPLICATION GUIDANCE:
  • Solution Strength: 0.5% – 1.0% aqueous Ferrous Sulphate solution
  • Application Mode: Foliar spray to prevent soil iron fixation
  • Frequency: 2 to 3 sprays at 10–15 day intervals during early growth stage
  • Agronomic Precedent: Standard ICAR & State University foliar spray recommendations

Arogya Bhoomi Dosage Adjustment Methodology

Arogya Bhoomi applies a rule-based formula to adjust base recommended application rates based on documented soil deficiency severity.

FORMULA:
Recommended Dosage (kg/ha) = Base Rate (kg/ha) × Severity Multiplier

Current Rule-Based Multipliers

Deficiency Severity Multiplier Adjustment Rationale
Low Deficiency 1.25x Higher dose required to build up depleted soil reserves.
Medium / Moderate 1.00x Standard baseline agronomic application rate.
High Deficiency / Mild 0.75x Lower maintenance dose for mildly deficient soils.

Base Reference Rates

  • Zinc Sulphate (ZnSO₄): Base Rate = 37.5 kg/ha
  • Potassium Chloride (KCl): Base Rate = 40.0 kg/ha
  • Ferrous Sulphate (FeSO₄): Foliar Application Spec (Foliar Branch)
